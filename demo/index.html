Import formats

Paste or upload .csv, .txt, .json, or .geojson. Separators can be comma, semicolon, or tab. Lines starting with # are ignored. Excel (.xlsx), polygons, and lines are not imported.

CSV / text — coordinates only

Id is left blank and auto-numbered (1, 2, 3…).

45.4642, 9.1900
45.4863, 9.2045

CSV / text — id, latitude, longitude

duomo, 45.4642, 9.1900
navigli, 45.4515, 9.1750

CSV with a header

Accepted names: id / origin_id, lat / latitude, lon / lng / longitude.

id,lat,lon
duomo,45.4642,9.1900
,45.4863,9.2045

GeoJSON Point features

A FeatureCollection or a single Feature. Id comes from feature.id, then properties.id, then properties.origin_id.

{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "id": "duomo",
      "geometry": { "type": "Point", "coordinates": [9.1900, 45.4642] }
    }
  ]
}
